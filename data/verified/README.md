# data/verified

Verified data: the **only** data normal mode loads. Every file uses the dataset
envelope in [../schema/dataset.schema.json](../schema/dataset.schema.json), and
every fact in it has a passing record in
[../../verification/records/](../../verification/records/). `npm test`
enforces this, and CI won't deploy if it fails.

- `elements/`: one file per element, generated by `python -m pipeline.elements`.
  Don't edit these by hand; fix the pipeline and re-run it.
